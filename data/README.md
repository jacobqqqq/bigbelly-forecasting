# Data Directory

Raw CLEAN export files are excluded from this repository.

## Required files (not committed)

Place the following files in this directory before running the notebooks:

| File | Description |
|---|---|
| `Daily Collection Activity - CLEAN 2024 (1).csv` | CLEAN export covering Jan 2023 – Dec 2023 |
| `Daily Collection Activity - CLEAN 2025 (1).csv` | CLEAN export covering Jan 2024 – Dec 2024 |
| `Daily Collection Activity - CLEAN 2026 (1).csv` | CLEAN export covering Jan 2025 – Feb 2026 |

All three files use the CLEAN Management Console export format with a 10-row metadata header.
The notebooks handle this automatically.

## Committed files

| File | Description |
|---|---|
| `bin_fill_curve_coefficients.csv` | Per-bin fill-curve coefficients (sigmoid/saturating/power-law/log/linear), R², predicted fill at 24h/48h/72h, and wasted trip rate. 224 rows (one per bin-stream with sufficient history). Generated by `01_fillcurve_forecast.ipynb`. |

## Schema: CLEAN export

| Column | Description |
|---|---|
| Serial | Bin serial number |
| Description | Location name |
| Capacity | Hardware type (Smart Max) |
| Stream Type | Waste / Compostables / Bottles/Cans |
| Reason | Fullness / Not Ready / Age / Alert |
| Fullness Level at Collection | 0% / 20% / 40% / 60% / 80% / 100% |
| Collection Time | MM/DD/YYYY H:MM timestamp |
| Note | Free text (mostly "-") |
